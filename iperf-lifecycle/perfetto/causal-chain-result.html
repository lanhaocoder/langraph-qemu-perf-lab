ftrace → Perfetto · 带因果链的转换结果

把 QEMU Guest 里 20 线程双向 TCP iperf 的 ftrace.log 转成 Perfetto 调度 trace，并把「中断 → 唤醒 → 上 CPU」用 flow 箭头串起来。

180,083 条 tracepoint 43,954 条 flow 1,510 条 iperf3 链闭合到上CPU 官方校验零 health 告警 pftrace + JSON 双格式

① 一条真实完整因果链

从 iperf-lifecycle.json 里按 flow id 还原（flow id=26422，4 节点，跨度 261 µs）。红箭头从 IRQ/softirq 轨跨到 CPU 运行轨，即 Perfetto 里的因果连线。

② 原始事件（转换后 JSON 里的真实记录）

每个节点都是 Chrome Trace Event 的 ph:"s" / ph:"f" flow 事件，共用同一个整数 id。

#相对时刻ph所在轨nameargs角色
1+0.0 µs ph:"s"CPU0 IRQ / softirq 软中断 raise vec=9 [RCU]vec=9 · action=RCU 起点
2+80.0 µs ph:"f"CPU0 IRQ / softirq 中断/软中断 → 唤醒 iperf3woken_pid=408 · comm=iperf3 · target_cpu=1 步进
3+152.0 µs ph:"f"CPU1 运行 sched_wakeuppid=408 · comm=iperf3 · target_cpu=1 · flags=dNH2. 步进
4+261.0 µs ph:"f"CPU1 运行 上CPU运行（中断→唤醒→运行）pid=408 · wake2run_us=109.0 · target_cpu=1 终点
语义：① 软中断里处理收包、置位 → ② sock_def_readable() 触发 sched_waking 唤醒等待 socket 的 iperf3 → ③ sched_wakeup 入运行队列并置 NEED_RESCHED → ④ sched_switch(next_pid=408) 真正上 CPU。wake2run_us=109 是入队到上 CPU 的延迟。

③ 泳道预览（专用窗口 28.5698~28.5722 s）

从 iperf-chain.json 反绘。蓝色 = iperf3 在 CPU 上运行，灰色 = 各 CPU 的 idle（swapper/N:0 按 CPU 区分），青色 = NET_RX 软中断，红箭头 = 因果/唤醒 flow。

⑥ 为什么在 Perfetto UI 里「看不到因果链」

针对 iperf-lifecycle.pftrace 的实测结论：数据没丢，是查看方式与我的实现两个问题叠加。

层面核查结果判定
数据层flow=43,954 · 配对 id 正常 · 跨轨 4,641 · 节点齐全（软中断raise 15,746 / 唤醒 1,904 / 上CPU运行 1,823 / 硬中断 74）转换没丢链
Perfetto UI 机制官方文档原话："The link is displayed as an arrow in the UI, when one of the events is selected." 4.4 万条箭头不会默认全画，必须点选端点事件才显示。客观机制
我的实现pftrace 的 43,954 条 flow 两端 100% 是 dur=0 的 instant（UI 里是 1px 紫色三角）；而 .json 版有 34,548 条端点落在有宽度的 slice 上。26 秒全量视图下三角完全不可见、也点不中。我的缺陷
交付指引没写「放大到 ms 级 + 点选三角」的步骤；之前内联画的是手绘 SVG，不是 Perfetto UI 截图。我的缺陷
原始日志irq_handler_entry 仅 74 条，softirq_raise 15,746 条 → 完整「硬中断→软中断→用户态」链在这份 ftrace 里几乎不存在，链多从 NET_RX 软中断起。抓包配置
想看到箭头，按这 4 步：
① 打开 iperf-chain.pftrace（2.4ms 专用窗口，别用 26s 全量）或 iperf-chain.json；
② 展开「CPU 运行泳道」「IRQ/softirq 轨」；
③ 滚轮放大到刻度显示 00:000 500 000 量级（0.5~2ms 视野）；
④ 点选紫色三角 ▲（instant 端点）或有宽度的 slice → 相连的 flow 箭头才会画出来，详情面板出现 Flow 字段。
最省事：直接看本页 ① 节的 SVG 链图，它就是这条链的真实数据，不依赖 UI 交互。
